# Notes

## MSI laptop keyboard backlight

On an MSI laptop (Windows 10) the keyboard backlight brightness is changed with **Fn + `+`** and **Fn + `-`** (the numpad keys). The Fn keys are handled by the laptop's firmware, so the macro and the Discord bot cannot press them; a bot command for it would have to go through the lighting software of the model (SteelSeries GG or MSI Center), if that has a command or a profile to switch.
